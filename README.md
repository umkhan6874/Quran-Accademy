# Quran Tutor Academy 📖✨

> A world-class, 100% free modern Quran learning web application for children, beginners, adults, parents, and teachers.

## Mission
"Make Quran learning easy, accessible, and completely free for everyone."

- **Zero subscriptions**
- **Zero premium paywalls**
- **Zero in-app ads**
- **100% Free Forever supported by Waqf continuous educational endowment**

## Features

- **Noorani Qaida**: Interactive 29 Arabic alphabet cards, Harakat (Fatha, Kasra, Damma), Tanween, Sukoon, and Tashdeed with articulation point (Makharij) guidance, speech synthesis pronunciation, and recognition quiz.
- **Nazra & Quran Reader**: Complete Surah directory with authentic Uthmani calligraphy, verse-by-verse repetition loop player (1x, 3x, 5x, 10x), ayah bookmarks, Tafsir contextual insights, and font size adjustment (20px to 42px).
- **Tajweed Master**: Detailed rules for Noon Saakin & Tanween (Izhar, Idgham, Iqlab, Ikhfa), Qalqalah (echo letters), and Ghunnah with color-coded Quranic examples.
- **Hifz Memorization Tracker**: The traditional 3-pillar method (Sabaq, Sabqi, Manzil) with an interactive circular repetition counter and mastery roster.
- **Verified Tutors Directory**: Search and filter qualified teachers (Al-Azhar / Madinah graduates) with Ijazah sanad chains, reviews, and 100% free trial class booking.
- **Live Virtual Classroom**: Full dual-video simulation, student mic/camera controls, shared Quran Mushaf whiteboard, live chat with teacher feedback, and raise-hand feature.
- **AI Quran Tutor (Ustadhi AI)**: Friendly, respectful study guide for Tajweed rules, letter pronunciation, and verse meanings with Kids Mode toggle.
- **Parent Guardian Portal**: Track children's attendance, weekly study time (4.5 hrs), teacher lesson feedback, and homework checklists.
- **Teacher Instructor Studio**: Daily schedule, new free trial requests queue with instant approval, and custom homework assigner.
- **Islamic Everyday Tools**: Digital Tasbeeh beads counter with vibration support, daily authentic Duas & Azkar, calculated prayer times with Qibla compass bearing, and 40 Hadith pearls.
- **SEO & Accessibility Ready**: Semantic HTML5, Meta/OpenGraph tags, high-contrast accessible design, and responsive mobile-first navigation.
- **Safe LocalStorage Persistence**: Caches user profile, role, scheduled bookings, bookmarks, and completed lessons without ever storing passwords.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Storage**: Browser LocalStorage
- **Design System**: Responsive CSS with CSS Custom Properties, light/dark themes, and Google Fonts (Plus Jakarta Sans & Amiri)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
